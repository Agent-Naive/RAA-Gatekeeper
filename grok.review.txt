## 2. Key UI Layout Decisions (Ledger View) — Current Specs

### Left Pane (File List)
- Width: `flex: 0 0 300px` (locked here after iterative testing — user approved)
- `overflow-x: hidden` on both the panel and list container (prevents ugly horizontal scrollbars)
- Search/filter input lives in `.ledger-header` with `padding: 6px 8px` + `box-sizing: border-box`
- Rows now use a two-line structure:
  - **Top line:** Icon (🛡️/🚨) + filename (flex-1 + `text-ellipsis` + `min-width: 0`)
  - **Bottom line:** Date (left) + 🗑 delete button (right)
- Row padding: `6px 8px`
- Consistent 8px right gutter on both the filename line and the date+trash line to align with the filter input's right edge.

### Right Pane (Detail View)
- `min-width: 480px`
- `max-width: 620px`
- `flex: 1`
- `padding: 12px` (all sides)

### Gap Between Panes
- Reduced to `gap-8` (from `gap-12`) during balancing work.

### Delete Functionality
- Per-report delete button (🗑) appears on hover in the list.
- Custom confirmation modal (`.delete-confirm-overlay` + `.delete-confirm-dialog`) with clear warning.
- Backend command: `delete_ledger_file(fullPath, vaultRootPath)` with safety checks:
  - Must be inside current vault root
  - Must be a `.raa` file
  - Proper error handling
- After delete: list auto-refreshes; if the deleted report was open, detail pane clears cleanly.

## 3. Integrity Guard (Restored)

**Problem:** During the big CSS cleanup, `.integrity-grid` and `.check-item` styles were completely lost. The section was crammed inside a generic `.welcome-card` and looked broken.

**Solution Implemented:**
- Created dedicated `.integrity-container` (with its own background, border, padding).
- `.integrity-grid` uses CSS Grid: `repeat(auto-fit, minmax(260px, 1fr))` with good gap.
- Each `.check-item` is a proper card with background, border, and nice internal spacing.
- Status icons (✅ / ❌) are larger and visually clear.
- The 7 checks from `check_integrity` are now well spaced and readable.

**Backend:** `check_integrity` returns a JSON object with 7 boolean fields. All currently hard-coded to true except real runtime checks for `parallel_hashing`, `bucket_traversal`, and `vault_path`.

**Note:** `.welcome-card` style still exists in the component `<style>` block but is no longer used for Integrity.

## 4. CSS Architecture Status

**Major Ongoing Initiative:** Move away from bloated inline styles and component `<style>` blocks toward a clean, external design system.

**Current State:**
- Primary styles live in `src/app.css` (global tokens, components, utilities).
- `src/routes/+layout.svelte` imports `../app.css` globally (simple and correct pattern).
- Many component-specific styles were pruned from `+page.svelte` during cleanup.
- Some styles remain in the component's `<style>` tag (e.g., `.welcome-card`, DNA styles, some older utilities). These are being gradually reviewed.

**User Preference (Strong):**
- Contributor-friendly structure.
- Prefer external CSS over heavy in-component styles or Tailwind bloat.
- Keep the design system clean and maintainable.

**Recent Related Work:**
- Added many utility classes in app.css (`.flex`, `.gap-*`, `.text-*`, etc.).
- Created `.ledger-delete-btn`, delete modal styles, integrity styles, etc. directly in app.css.

## 5. Critical Known Issues & Documentation

### HIGH PRIORITY: The "ALLSAFE" Bug (Certify)
- **File:** `knownbug.ALLSAFE.txt` (detailed spec)
- **Summary:** `generate_manifest` (Certify) **always** returns "Success. Report stored in RAA_Vault" even when many files are flagged as "RAA VIOLATION DETECTED".
- The ledger correctly records the violations per file, but the overall operation and UI treat it as a clean success.
- This completely breaks the meaning of "Certify."
- **Status:** Documented in ROADMAP.md under a new "🚨 Critical Bugs" section.
- **Next Step:** Change `generate_manifest` to return a proper `RAAReport`, track violations, and update the frontend to show failure states.

### Other Notes
- Rich per-file AI analysis is now being written for **Archive** (ZIP) audits using `--- RAA FILE ANALYSIS ---` blocks. This is a big improvement in forensic value.
- Certify still uses the old flat format (work for later).
